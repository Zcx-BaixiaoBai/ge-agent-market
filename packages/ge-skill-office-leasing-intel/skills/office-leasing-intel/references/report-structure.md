# 招商评估报告结构与措辞

## 报告骨架（单城市或多城市通用）

1. 封面/题头 + 一行“数据日期 ｜ 数据源：地图 POI 快照与步行/驾车路径实测 + 公开市场资料”。
2. 〇、一页结论：每栋一句话定位 + 组合风险，先给判断再给论证。
3. 一、数据口径与使用须知：圈层半径、三口径、600 上限、点评弱信号、内部数据不在内。
4. 组合画像与城市能级（多城市时）：市场分档（省会/地级市/县级市等）与楼宇产品分型。
5. 分市场客观现状与真实竞争力（公开口径）：市场行情表 → 楼宇公开挂牌表 → 每栋真实竞争力判断
   （优势/风险/比价对象）。**这是“资产真实竞争力”章节，必须给客观现状而不是只讲卖点。**
6. 项目档案与检索中心：名称、坐标、区县街道、公开参数；同园区多栋注明共用检索中心。
7. 商圈成熟度与配套密度：指标表 + 热力图；按“商圈资源型/企业密度型/综合体自带型/区域中心型”解读。
8. 竞品盘点与聚集密度：密度总览表（三口径）+ 各项目直接竞品名单（去重后按距离）+
   关键竞品的评分与“比价对象”；对外建议用去重口径。
9. 企业/租户结构与产业氛围：行业结构表/图 + 可确认的落址企业样本 → 目标客户建议。
10. 交通可达性实测与话术：表格（站点/线路/直线距/出入口/实测步行）+ 可直接进楼书的一句话话术。
11. 全量评分卡：维度分表 + 权重 + “读分须知”（相对模型、不含硬件、无轨交口径不适配等）。
12. 分层定位与差异化打法：按城市或产品层给出定位标签/目标客户/一句话打法。
13. 跨项目协同与监测：客户线索分派表 + 月度/季度监测清单 + 资料来源注记。

## 必须写清楚的边界

- 章节名“公开口径”时，正文只能出现公开市场报告、公开挂牌、楼宇公开参数和 POI 快照。
- 内部数据（出租率/收缴/成交条款）只允许出现在“建议另行补录”的说明里，不允许出现数值；
  若用户要内部版，输出独立文件并标注“内部决策版，请勿外传”。
- 每家机构/平台的数字并排展示，注明来源与日期，不做无依据的折中。
- 报告全文避免出现数据服务/接口名；统一说“地图 POI 快照”“步行/驾车路径实测”。

## 图表建议（2–4 张足够）

- 定位四象限：横轴=1.5km 写字楼去重数（竞争密度），纵轴=区位-商圈综合分，气泡大小=企业密度。
- 配套热力图：行=项目，列=餐饮/咖啡/酒店/商场/企业/写字楼等，直接标注数值，触顶写“≥600”。
- 行业结构：横向 100% 堆叠条，展示科技/建筑/广告/贸易等第一梯队差异。
- 竞品 vs 企业密度：双系列柱状图，直观呈现“去化压力”与“产业聚人”两个视角。

## Word 排版约束

- 纸张 A4（21×29.7cm），页边距可 2.54cm；正文宽约 9026 DXA，表格/图片宽度必须按该内容宽重算，
  不能沿用 Letter 的 9360。
- 表格需统一几何（tblW/tblGrid/tcW 一致）、表头可跨页重复；数值列居中、文本列左对齐。
- 中文正文用微软雅黑/宋体等系统字体；封面题头与页眉标题按报告主题生成。
- 渲染校验：优先渲染逐页看图；若 LibreOffice/看图不可用，用 Word COM 转 PDF + 文本/结构校验，
  并如实说明“未能做像素级视觉复核”。

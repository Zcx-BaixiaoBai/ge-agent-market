# 写字楼招商情报分析（office-leasing-intel）

把一批写字楼项目变成可招商、可汇报的中文评估报告：每个项目给出区位画像、周边竞品、配套与产业密度、
交通实测、公开市场定位和差异化打法，最后落成 A4 Word（另存 Markdown 源稿）。

> 开发者：颜政 · 内部使用 · 默认只输出公开口径，不包含出租率、收缴、实际成交租金等内部经营数据。

## 安装（金鹰 Agent 插件市场）

在桌面端「插件 → 发现」中搜索「写字楼招商分析」安装即可，安装后注册技能 `office-leasing-intel`。

## 前置条件

- **高德 Web 服务 Key**：必须设置环境变量 `AMAP_KEY`。本市场包**不内置任何 Key 或凭证**；
  缺少时 `scripts/amap_client.py` 会直接报错，不会回退到内置 Key。
- Python 3（只用标准库，无需第三方包）。
- 可选：设置 `AMAP_CACHE_DIR` 指向任务目录，复跑时复用缓存、少扣配额。
- 输出 Word 时配合 `documents`/Word 技能使用。

## 能做什么

- 项目定位：地址/项目名 → POI，记录坐标、区县、街道和公开楼宇参数
- 周边快照：按圈层抓取写字楼、企业、餐饮、咖啡、便利店、酒店、银行、公园、商场、轨交 POI
- 清洗与指标：写字楼原始/清洗/去重三口径、配套类目计数、企业行业归类、步行/驾车实测
- 公开市场层：机构季度报告 + 公开挂牌样本；没有权威数据时明确写「仅挂牌样本参考」
- 评分卡：交通 25%、配套 30%、产业 20%、竞争 10%、口碑 15%，只用于组合内排序解释
- 报告：按章节骨架输出 Markdown，配定位四象限、配套热力、行业结构、竞品/企业密度图

## 使用示例

```text
帮我分析南京金鹰世界、珠江壹号和昆山金鹰三个写字楼项目的区位与招商竞争力
盘一下这个园区在周边 1.5km 的竞品供给、产业密度和轨交可达性
给这几个项目出一份 A4 招商评估报告，结论落到目标客户和差异化打法
```

## 口径与边界

- 默认不展示内部经营数据；如需内部版，另出明确标注「内部决策版」的文件。
- 报告正文不出现数据服务/接口名称，统一表述为「地图 POI 快照」「步行/驾车路径实测」。
- 挂牌价 ≠ 成交价；机构口径并排展示，不混算。
- 写字楼数量对外用去重口径；企业名单是地图标注样本，不是完整花名册。
- 评分不预测租金，只用于组合内排序解释。

# 123 物联网平台 MCP 技能

> 9 个工具 | HTTP + MQTT 混合架构 | https://cloud.sd123iot.com:8443

---

## 何时使用

当用户需要操作 123 物联网云平台（sd123iot）：
- 查看设备列表、在线状态
- 获取设备实时数据（温度、湿度、电压、水浸等）
- 按项目统计设备数量和在线率
- 查看设备告警和离线设备

**关键词**: 123物联网、sd123iot、设备监控、MQTT、水浸、配电房、温湿度、烟感

---

## 架构说明

```
123平台 HTTP API 极简（仅2个端点）：
  /user/login    → 登录
  /dev/getDevs   → 获取设备列表

所有实时数据走 MQTT 推送：
  服务器: wss://comm.sd123iot.com:443/mqtt
  用户名: 账号名
  密码: t:{token}
  订阅: /app/data/{设备ID}/u

MCP Server 架构：
  启动时 → 登录全部账号 → 获取设备列表 → 建立MQTT → 订阅所有设备
  运行时 → MQTT推送 → 更新内存缓存
  查询时 → MCP工具直接读内存缓存（延迟<1秒）
```

**数据规模**: 23 个项目、783 台设备、613 台在线

## 一、连接与配置（2 个工具）

### configure

配置连接参数和多项目账号。

```
configure(
    accounts_json='[
        {"project":"项目A","account":"账号A","password":"密码A"},
        {"project":"项目B","account":"账号B","password":"密码B"}
    ]',
    mqtt_server="comm.sd123iot.com"
)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| accounts_json | str | `""` | 账号列表 JSON 数组 |
| base_url | str | `"https://cloud.sd123iot.com:8443/usrCloud"` | HTTP API 地址 |
| mqtt_server | str | `"comm.sd123iot.com"` | MQTT 服务器 |

**账号 JSON 格式**:
```json
[
    {"project": "项目名", "account": "登录账号", "password": "密码"},
    ...
]
```

config.json 已预配置 23 个项目账号（芜湖国际、芜湖商城、苏州、盐城金鹰天地、盐城奥莱、仙林、丹阳、扬州文昌、扬州新城市、南通中心、马鞍山、珠江壹号、金鹰中心、昆明、昆山、淮安、汉中、淮北、宿迁、泰州、江宁、扬州京华、南通人民路）。

## 二、设备查询（2 个工具）

### device_list

列出所有设备。

```
device_list()                    # 全部783台
device_list("芜湖国际")           # 按项目筛选（48台）
device_list("昆山")              # 按项目筛选（90台）
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| project | str | `""` | 按项目名筛选（留空返回全部） |

**返回字段**:

| 字段 | 类型 | 说明 |
|------|------|------|
| devid | string | 设备 ID |
| name | string | 设备名称 |
| project | string | 所属项目 |
| groupName | string | 设备分组 |
| template | string | 设备类型 |
| onlineStatus | string | 在线/离线 |
| address | string | 地址 |
| sn | string | SN码 |
| imei | string | IMEI |
| mac | string | MAC地址 |
| verifyCode | string | 验证码 |

**使用场景**:
```
用户: "看看芜湖国际有哪些设备"
→ device_list("芜湖国际")
→ 返回48台设备，含名称、类型、在线状态
```

## 三、实时数据（2 个工具）

### realtime_data

获取单个设备最新实时数据。

```
realtime_data("085202104252643")
```

| 参数 | 类型 | 说明 |
|------|------|------|
| devid | str | 设备 ID |

**返回**:
```json
{
    "devid": "085202104252643",
    "name": "13524-写字楼48楼高配",
    "data": {
        "温度": 25.3,
        "温度_time": 1717901400,
        "湿度": 62.1,
        "湿度_time": 1717901400,
        "电压A": 220.5,
        "电流A": 12.3,
        "_updateTime": "2026-06-09 11:30:00"
    }
}
```

⚠️ 如果设备暂无实时数据，返回错误提示。可能原因：MQTT 未连接或设备未上报。

### realtime_all

获取所有设备实时数据。

```
realtime_all()                # 全部（数据量大！）
realtime_all("芜湖国际")       # 按项目筛选
realtime_all("昆山")          # 按项目筛选
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| project | str | `""` | 按项目筛选（留空全部） |

⚠️ 全量返回数据量很大（783台），建议加 project 参数筛选。

## 六、通用 API 调用（1 个工具）

### api_call

直接调用 123 平台 HTTP API（仅 2 个端点）。

```
# 登录
api_call("POST", "/user/login", json_body='{"account":"金鹰物业集团","password":"md5值"}')

# 获取设备列表
api_call("POST", "/dev/getDevs", json_body='{"pageNo":1,"pageSize":100}')
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| method | str | 必填 | GET / POST |
| path | str | 必填 | API 路径 |
| params | str | `"{}"` | URL 参数 JSON |
| json_body | str | `"{}"` | 请求体 JSON |

⚠️ 123 平台 HTTP API 极简，仅 `/user/login` 和 `/dev/getDevs` 两个端点可用。其他数据全部走 MQTT 推送。

## MQTT 协议详解

### 连接参数

| 参数 | 值 |
|------|-----|
| 服务器 | `comm.sd123iot.com` |
| 端口 | `443`（WebSocket over TLS） |
| 用户名 | 登录账号 |
| 密码 | `t:{token}` |
| 客户端 ID | `mcp_{账号}_{时间戳}` |

### Topic

| Topic | 方向 | 说明 |
|-------|------|------|
| `/app/data/{devid}/u` | 订阅 | 设备实时数据推送 |
| `/app/status/{devid}` | 订阅 | 设备上下线通知 |

### 消息格式

```json
{
    "deviceId": "085202104252643",
    "dataPoints": [
        {
            "variableName": "温度",
            "value": 25.3,
            "time": 1717901400,
            "dataPointId": "dp001",
            "slaveIndex": 1
        }
    ]
}
```

### 上报频率

| 设备类型 | 频率 |
|----------|------|
| NB-IoT 设备 | 5-30 分钟 |
| 4G 设备 | 1-5 分钟 |
| 水浸传感器 | 事件触发（浸水即报） |

### 数据延迟

实时数据延迟取决于设备上报频率：
- 最快: 1 分钟（4G 设备）
- 最慢: 30 分钟（NB-IoT 设备）
- 水浸: 即时（事件触发）

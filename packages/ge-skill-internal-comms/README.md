# ge-skill-internal-comms

内部沟通写作技能：状态报告、领导更新、3P（Progress/Plans/Problems）、公司通讯、FAQ、
事故报告、项目更新。技能内置四类模板/示例，写之前先选对格式。

> 来源：Anthropic [skills/internal-comms](https://github.com/anthropics/skills)（Apache-2.0）。

## 安装（金鹰 Agent 插件市场）

在桌面端「插件 → 发现」中搜索「内部沟通」安装即可，安装后注册技能 `internal-comms`。

## 能做什么

- 3P 周报（进展/计划/问题）
- 公司通讯、领导更新、项目更新
- FAQ、事故报告、状态报告
- 按 `examples/` 里的格式模板起草，保持公司统一口吻

## 使用建议

直接说明受众、目的、时间范围和需要强调的事实；技能会选择对应模板并给出初稿，
涉及对外发布或敏感数据时请人工复核。

# 报告样式规范（金鹰暖色财务风）

> 办公业态经营分析报告对外输出 HTML 时的**固定视觉风格**。任何生成 HTML 报告的场景必须套用本规范，不得另起样式。
> 风格来源：《南京建邺金鹰购物中心月度财务分析报告》打印版（用户指定参考样本），经多轮用户评审定稿。

## 风格定位

暖色纸张质感财务报告风：**米色纸张背景、金色品牌主色、深棕表头、宋体封面标题、模块化分析卡片**。庄重、高档、打印友好。核心气质是"纸质财报"而非"数据大屏"——全站无纯白/纯黑，所有颜色偏暖黄调。

参考实现：定稿样板（含全部组件；本市场包不含示例 HTML，按本文规范生成即可）。

| `.increase` | `--red` 红 | 上涨/增加（涨红） |
| `.decrease` | `--green` 绿 | 下降/减少（跌绿） |
| `.num-red` / `.text-red` | 红 | 负值/缺口/流失/低于竞品 |
| `.num-green` / `.text-green` | 绿 | 正向/达标 |

| `.text-muted` | `--muted` | 数据缺失（显示为 "-"） |

## 页面结构与组件规范

### 1. 顶部导航栏（.topbar）

- `position: sticky` 置顶，高 54px，毛玻璃 `backdrop-filter: blur(16px) saturate(1.6)`
- 左侧 `::before` 伪元素：5px×28px 金色渐变竖条 + 品牌名（15px/700/`--gold-deep`）
- 链接 12px，悬停/激活时 `--gold-deep` 字 + `--tag-bg` 底
- 配 scroll spy：滚动时高亮当前章节

### 2. 左侧浮动导航（.module-rail）—— 默认展开

- `position: fixed; left: 12px; top: 50%`，**宽度固定 180px（常规展开，禁止做成 hover 才展开）**
- 圆角 22px + 毛玻璃 + 浅边框
- 分组显示（概览/分析/财务/决策），组标题 9px 金色大写字距
- 每项 = 圆点（8px）+ 文字（12px）；激活项圆点变金色、文字加粗
- 打印时隐藏

### 3. 封面页（.cover-page）

- 背景 `--paper-deep`，`min-height: 1060px`，相对定位，`padding: 80px 60px`
- 装饰：`::before`/`::after` 两个金色细圆环（右上 320px、左下 200px，opacity .5/.3）
- `.cover-logo`：宋体 16px、金色、字距 6px
- `.cover-title`：宋体 38px/700/`--gold-deep`，字距 4px
- `.cover-subtitle`：20px 报告期间（如"2026年1-10月（累计）"）
- `.cover-meta`：数据截止日/生成日期/报告类型/保密级别，每行前加金色 `—`
- `.cover-toc`：底部绝对定位，双列网格目录；章节编号用**中文小写数字（一二三四…十），禁用大写壹贰叁，禁用英文 CHAPTER 01**
- 打印时 `page-break-after: always`（封面独占一页）

### 4. 章节标题层级

| 层级 | 类名 | 样式 |
|------|------|------|
| 章标题 | `.section-heading` | 22px/700，`padding-bottom:12px` + 2px `#493a20` 下实线。**标题只写中文（如"一、管理层摘要"），不加 CHAPTER 01 类英文前缀** |
| 节标题 | `.section-subhead` | 17px/600，左侧 4px 金色竖条 |
| 话题标题 | `.topic-heading` | 15px/600，前置 22px×3px 金色渐变装饰条 |
| 编号话题 | `.topic-heading--numbered` | 浅金渐变底条 + 金色渐变方形编号徽章（白字 11px） |

每个章节包在 `.section` 卡片中：`--paper` 底 + 1px `--line` 边 + `padding: 40px 48px`。

### 5. KPI 指标卡片（.metric-strip）

- 4 列等分网格（`grid-template-columns: repeat(4,1fr)`），卡片间 1px 浅边线分隔
- `.mc-label` 11px 灰 / `.mc-value` 24px/800 等宽数字 / `.mc-desc` 11px 灰
- 值配色：默认 ink，`.mc-red` 红（缺口/负向）、`.mc-green` 绿、`.mc-gold` 金（判断词，如"量价齐跌"）
- 2 列变体：行内 `style="grid-template-columns:1fr 1fr"`

### 6. 表格（table）

- 表头：深棕 `#3d3225` 底 + `--paper-deep` 字，11px/500，居中
- 单元格：12px、居中、等宽数字、`8px 10px` 内边距、`--line-light` 边框
- 斑马纹：偶数行 `rgba(227,202,143,.08)`；hover `rgba(227,202,143,.15)`
- **关键行 `.key-financial-row`**：`#f1e3c2` 底 + 850 字重 + 上下 2px 金色边线（用于合计行/可控利润行）

### 7. 分析模块（四种，语义固定）

| 模块 | 类名 | 视觉 |
|------|------|------|
| 简要分析 | `.brief-analysis` | 左 3px 红竖条 + 红色浅渐变底，左上角红色渐变标签"简要分析"（::before 自动生成） |
| 结论 | `.conclusion` | 同上红色系，::before 显示红色"结论"标签 |
| 问题提示 | `.insight-block.problem` | 左 3px 金竖条 + 金色浅渐变底，::before 显示"● 问题提示" |
| 管理建议 | `.insight-block.recommendation` | 左 3px 绿竖条 + 绿色浅渐变底，::before 显示"● 管理建议" |

模块内 `strong` 一律 `--gold-deep` 色。`.brief-analysis p` 需 `margin-top: 18px` 避开标签。

### 8. 标签与警示块

- 标签 `.tag`：2px×8px 内边距、10.5px；`.tag-danger` 红 / `.tag-warn` 橙（`#b5651d`）/ `.tag-info` 绿 / `.tag-gold` 金
- 警示块 `.alert-*`：`.alert-warn` 金边浅金底（异常标注）/ `.alert-danger` 红边浅红底（重点关注）/ `.alert-info` 绿边浅绿底（数据说明）

### 9. 风险列表（.risk-list）

- 每条 `.risk-item`：白底卡片 + 左 4px 红边
- 标题前置红色渐变徽章 `.risk-badge`（如"利润缺口"/"空置风险"/"数据缺失"）

### 10. 行动建议（.action-group）

- 三组圆点配色：`.ag-urgent`（30天内）红点 / `.ag-mid`（90天内）金点 / `.ag-kpi`（考核建议）蓝点 `#2980b9`
- 列表项前置金色空心圆点，项间虚线分隔

## 图表规范（Chart.js + 数据标签）

- **必引两个 CDN**：`chart.js@4.4.1/chart.umd.js` + `chartjs-plugin-datalabels@2.2.0`
- **所有图表必须显示数据标签**（领导要求直接在图上看数，不翻表格）：在 `chartDefaults.plugins.datalabels` 中配置——
  - `display: true`，`anchor: 'end'`，`align: 'top'`，`offset: 2`，10px/600
  - `formatter`：`|v|>=10000` 时显示 `(v/10000).toFixed(1)+'万'`，否则千分位 1 位小数
  - 水平堆叠条形图（C3）单独覆盖：`align: 'right'`、9px
- **合并陷阱**：各图表用 `Object.assign({}, chartDefaults.plugins, {...})` 覆盖 title/legend 时，必须显式带上 `datalabels: chartDefaults.plugins.datalabels`，否则 datalabels 被浅合并吃掉、图上不出数
- 调色板：`#77591f`（深金主系列）、`#ad883b`（金）、`#e3ca8f`（浅金/空置）、`#b8ad9e`（灰，同期对比）、`#b4473d`（红，掉铺/负向）、`#23715c`（绿，达标）
- 出租率配色按值分档：`>=80` 绿 / `>=60` 金 / `>=40` 暗黄 `#d4a017` / `<40` 红
- 图尺寸：双图行 `.chart-row`（各 270px 高）；单图 `.chart-box` 300-380px 高

## 文案与格式约定（用户评审定稿）

- 报告名称统一为「**写字楼租赁业务经营分析**」（title、顶栏品牌、封面标题、页脚四处一致）
- **禁用 `pct`，一律写 `%`**（如"微降 0.3%"）
- 章节编号：中文小写数字"一、二、三…十"，附录用"附"
- 单位：金额万元、面积㎡、租金元/㎡/天，百分比保留 1 位小数
- 页脚：`写字楼租赁业务经营分析报告 · YYYY年1-N月（累计） · 内部资料，请勿外传`

## 打印与 PDF 规范

HTML 内嵌 `@media print` 只做最基础处理；PDF 可用本机浏览器或文档技能按下列参数导出：

| 项 | 规范 |
|----|------|
| 纸张 | A4 纵向，`printBackground: true`（保留全部背景色/图表色） |
| 页边距 | **上下左右各 5mm**（注意：HTML 内 `@page` 规则的 margin 会覆盖 Puppeteer 设置，必须同步改为 `margin: 5mm`，否则 PDF 边距不生效） |
| 视口 | `width: 756, height: 1085, deviceScaleFactor: 2`（A4 减 5mm 边距后的 CSS px） |
| 媒体类型 | `emulateMediaType('screen')` 保留屏幕端渐变与配色 |
| 分页 | **封面独占一页**（`page-break-after: always`）；**章节之间不强制分页**（`.section` 用 `break-inside: auto`，内容自然流动） |
| 防截断 | `.chart-box / .table-wrap / .metric-strip / .brief-analysis / .conclusion / .alert / .risk-item / .insight-block` 设 `break-inside: avoid`；各级标题 `break-after: avoid` |
| 隐藏 | `.topbar`、`.module-rail` 打印时 `display: none` |
| 图表冻结 | 渲染前遍历 `Chart.instances`：`animation=false` + `resize()` + `update('none')`，再 `setTimeout 800ms` 后出 PDF |
| 打印缩放 | 表格 11px、正文 12.5px、封面标题 32px、KPI 卡 20px 等微调（见定稿样板的打印样式） |

## 响应式

`max-width: 800px` 时：隐藏 module-rail、metric-strip 改 2 列、chart-row 改单列、cover-toc 改单列。

## 页面骨架

```html
<body>
  <div class="topbar">品牌 + 章节目录链接（scroll spy）</div>
  <nav class="module-rail">分组浮动目录（默认展开）</nav>
  <div class="page-wrap">
    <div class="cover-page" id="cover">宋体大标题 + 金色圆环 + 双列目录</div>
    <div class="section" id="s1">一、管理层摘要（metric-strip + brief-analysis + 关注事项表）</div>
    ... 共十一个章节（结构见 报告模板.md） ...
    <div class="page-footer">报告名 · 期间 · 密级</div>
  </div>
  <script>scroll spy ×2 + Chart.js 图表（含 datalabels）</script>
</body>
```

章节结构与内容口径由 `报告模板.md`、`口径规则.md` 决定，本文件只负责视觉与输出工艺。

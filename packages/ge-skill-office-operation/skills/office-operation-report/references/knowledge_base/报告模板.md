# 报告模板

> 办公业态经营分析报告固定十一个章节骨架。**结论前置，数据紧跟，异常标注。**
>
> 本文件只定义章节结构与内容要求（Markdown 骨架）。输出 HTML 时的视觉风格统一见同目录《报告样式-财务风.md》。

---

## 一、管理层摘要

> **结论先行**：用 5-7 个要点概括全局，每个要点一句话结论 + 关键数字。

**必须包含以下要素：**

1. **总体判断**：一句话概括经营态势（如"整体出租率承压，量价分化加剧"）
2. **全年利润最大拖累**：指出利润缺口最大的项目及金额
3. **出租率与空置**：整体出租率、空置面积排名前三项目
4. **合同动态**：净吸纳正/负、重点掉铺项目
5. **租金量价**：以价换量 / 量价齐跌判断
6. **储备与招商**：储备覆盖倍数、重点客户进展
7. **需管理层决策事项**：列出需要高层介入的关键决策点

# 口径规则

> 办公业态经营分析报告的统一计算口径与数据处理规范。
> 2026-10-16 起默认数据源为 BI 取数产出文件 `data/写字楼经营分析-BI取数_{截止日}.xlsx`，sheet 布局详见 `数据源映射.md`「一·D」。

## 一、报告期间口径

- **默认报告期间**：自动识别 Excel 中最新的累计期间（如"B权责1-10月累计分析"→ 报告期间为 2026年1-10月）。
- **报告截止日**：以「取数日志」sheet 的"报告截止日"为准（=取数当日的前一天）。
- **对比期间**：
  - 去年同期：B权责表中"2025年1-N月"行组。
  - 上年全年：B权责表中"2025年全年"行组。
  - 全年预估：B权责表中"预估2026年全年"行组。
- **C 合同情况/流失统计、F 储备两表的期间**：本年累计（本期开始/开始时间固定 2026-01-01，本期结束/结束时间=报告截止日），报告文案表述为"本年累计"，不得表述为"本周"。
- **若存在多期累计表**（旧模板场景），**优先使用最新累计期间**。

## 二、数据来源优先级

按以下顺序取值，高优先级覆盖低优先级（括号内为 BI 产出文件实际 sheet，前缀匹配）：

1. **B权责1-N月累计分析**（最高优先级）— 面积、出租率、收入、支出、利润、EBITDA、同比、全年预估、租金变化
2. **B收入支出明细 / B出租面积明细** — 项目级明细，与 B权责交叉校验
3. **A基础信息(出租+收入)** — 出租率/收入累计目标与达成率
4. **C合同情况(本年累计)** — 新签/续签/掉铺数量·面积·明细
5. **C流失统计(本年累计)** — 掉铺归因（流失原因、代表租户、经营类别）
6. **F储备转化分析 + F储备明细** — 招商漏斗（可跟进面积用转化分析表；三态客户数用明细表）
7. **D办公业态竞品** — 竞品租金、出租率、优劣势

> 旧模板的「权责（1-6月）」「B整场平均租金单价」「F租户储备分析」在 BI 产出文件中不存在，相关指标按上述替代来源取数（详见数据源映射.md 一·D）。

## 三、核心计算口径

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 出租率 | 已出租面积 ÷ 可租赁面积 | 取 B权责表原始值，若与面积不匹配则以面积计算值为准 |
| 空置面积 | 可租赁面积 − 已出租面积 | — |
| 空置占比 | 空置面积 ÷ 可租赁面积 | — |
| 净吸纳面积 | 新签面积 − 掉铺面积 | 正值=净吸纳，负值=净流失 |
| 在营均价/平均租金 | 直接取 B权责 R28（在营均价·坪效）、R29（平均租金） | BI 无"新增租户租金（面价/净价）"行，存量 vs 新增对比降级为：在营均价 vs 本期新签明细推算（可选）或标注"数据未提供" |
| 收入缺口 | 全年预估收入 − 上年全年收入 | 正值=增长，负值=缺口 |
| 利润缺口 | 全年预估可控利润 − 上年全年可控利润 | 正值=增长，负值=缺口 |
| 储备覆盖倍数 | 可跟进储备面积 ÷ 当前空置面积 | 保留1位小数；可跟进面积来自 F储备转化分析（须剔除 >10000㎡ 单条异常值并双口径标注） |
| 以价换量判断 | 出租率升 + 租金降 = 以价换量；出租率降 + 租金降 = 量价齐跌 | 对比在营均价/平均租金（B权责 R28-R29）、出租率同比变化；BI 无新增租户租金，量价判断以存量租金+出租率趋势为主 |

## 四、财务权责口径

- **收入、支出、可控利润、EBITDA、同比、全年预估**：优先使用"B权责1-N月累计分析"（BI 行号：本期 R8-R13、去年同期 R14-R17、预估全年 R18-R23、上年全年 R24-R27）。
- **去年同期**：使用 B权责表"2025年1-N月"行组数据。
- **上年全年**：使用 B权责表"2025年全年"行组数据。
- **全年预估**：使用 B权责表"预估2026年全年"行组数据。
- **同比计算**：优先使用表中已有的同比变化值；若缺失则自行计算 (本期 − 去年同期) ÷ |去年同期|。
- **交叉校验**：B收入支出明细的本年累计收入/总支出应与 B权责 R8/R9 一致；不一致时以 B权责为准并标注差异。
- **支出口径**：总支出=收入×12%−财务支出（数据集 SQL 规则）；"本年全年实际"列=累计÷月份数×12 的年化预估，与 B权责"预估2026年全年"同源。

## 五、项目名称统一口径

- 项目名称以 **B权责表 R1 行**（项目名称行，C 列起）为准。
- BI 产出文件内三套名称体系的完整映射见 `数据源映射.md`「一·D」第 13 条：
  - 金鹰世界A/B → B权责表中"南京金鹰世界(含A、B座)"（A/B 在 A基础信息、C合同情况、F 两表中分开列示，关联长名时需 A+B 相加）
  - 珠江壹号 → "南京金鹰珠江壹号"
  - 昆山金鹰 → "昆山金鹰项目"
  - 芜湖滨江 → "芜湖滨江金鹰世界"
  - 丹阳金鹰天地 → "丹阳金鹰天地广场"
  - 芜湖商城（C流失统计中为"芜湖商业"）→ "芜湖商城/芜湖商业项目"
  - 金鹰中心A → "南京新街口金鹰中心(实业+国际集团)"
  - 马鞍山 → "马鞍山金鹰"
  - 盐城聚龙湖 → "盐城金鹰天地广场(聚龙湖)"

## 六、缺失与空值处理

- **目标数据为空**：不计算达成率，标注"目标未设定"。
- **项目无数据**（如马鞍山、盐城在 B权责 中已出租面积和出租率为空）：标注"数据未提供/待补全"，不纳入合计计算。
- **B固定填报 sheet 的产权面积/初始投资/仲量估值/租金列当前全空**（BI 填报卡未维护）：引用时标注"数据未提供/待补全"。
- **F储备明细无面积列**：已转化/已流失只做客户数统计，面积维度仅"可跟进"可用（F储备转化分析）。
- **F储备转化分析存在单条面积异常**（如 700800㎡）：>10000㎡ 单条须 ⚠️ 标注，合计给出含/剔除异常值两个口径。
- **文本型数值**：A 系列 sheet 数值以文本存储（含千分位、% 号），使用前须转数值。
- **不得编造数据**：所有数值必须来自 Excel 原始数据或基于原始数据的公式计算，严禁估算或填充。
- **月度数据缺失**：仅使用累计数据，不推算月度值。
- **取数日志有 ⚠️ 警告**（分区回退、关键卡无数据等）：对应章节标注"数据未提供/待补全"，第十一章如实引用警告原文。

## 七、结论输出口径

### 每章结构
- **结论先行**：每章第一句必须是结论性判断，后跟数据支撑。
- **数据紧跟**：以 Markdown 表格呈现核心数据。
- **异常标注**：数据异常处在表格下方用 ⚠️ 标注说明。

### 管理层摘要（第一章）必须包含
1. **总体判断**：一句话概括经营态势（如"整体出租率承压，量价分化加剧"）
2. **全年利润最大拖累**：指出利润缺口最大的项目及金额
3. **出租率与空置**：整体出租率、空置面积排名前三项目
4. **合同动态**：净吸纳正/负、重点掉铺项目
5. **租金量价**：以价换量/量价齐跌判断
6. **储备与招商**：储备覆盖倍数、重点客户进展
7. **需管理层决策事项**：列出需要高层介入的关键决策点

### 风险量化
- 每条风险必须包含具体数字（面积、金额、百分比），禁止纯定性描述。

### 行动建议
- **30天内**：紧急且可快速落地的措施
- **90天内**：中期策略性举措
- **考核建议**：与 KPI 挂钩的考核方向

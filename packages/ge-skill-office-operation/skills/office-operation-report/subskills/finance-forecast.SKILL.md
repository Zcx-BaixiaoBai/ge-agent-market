# 财务权责与全年预测

> 本技能是「办公业态报告总控」（office-operation-report）的专项子技能，与总控共用技能根目录；
> 知识库位于 `references/knowledge_base/`，数据文件与总控一致。

## 数据来源

> 默认数据文件：`data/写字楼经营分析-BI取数_{截止日}.xlsx`；sheet 按**前缀匹配**，行号以 `references/knowledge_base/数据源映射.md`「一·D」为准。

- **主要来源**：`B权责`（前缀匹配，如 B权责1-10月累计分析）— BI 实测行号：
  - R8-R13：2026年1-N月（收入、支出、可控利润、可控利润同比变化、ebitda、ebitda同比变化）
  - R14-R17：2025年1-N月（收入、支出、可控利润、ebitda）
  - R18-R23：预估2026年全年（收入、支出、可控利润、可控利润同比变化、ebitda、ebitda同比变化）
  - R24-R27：2025年全年（收入、支出、可控利润、ebitda）
- **明细校验来源**：`B收入支出明细`（本年累计收入/总支出、上年同期、本年全年实际、上年全年实际，9 列）— 与 B权责 R8/R9/R14/R15/R18/R19/R24/R25 交叉校验，不一致以 B权责为准并标注
- **补充来源**：旧模板「权责（1-6月）」仅在 BI 文件缺失时回退使用
- **列结构**：R1 行为项目名称（C 列起每列一个项目，C=合计），R2 为位置描述
- 马鞍山、盐城：R8 起财务数据为空 → 标注"数据未提供/待补全"，不纳入合计

## 计算逻辑

| 指标 | 公式 | 说明 |
|------|------|------|
| 收入缺口 | 全年预估收入 − 上年全年收入 | 正值=增长，负值=缺口 |
| 利润缺口 | 全年预估可控利润 − 上年全年可控利润 | 正值=增长，负值=缺口 |
| 利润同比变化 | 本期可控利润 − 去年同期可控利润 | 直接使用表中 R11 值 |
| 全年利润同比变化 | 全年预估可控利润 − 上年全年可控利润 | 直接使用表中 R21 值 |

- 合计列（C列）为所有项目汇总
- 马鞍山、盐城若数据为空，标注"数据未提供/待补全"，不纳入合计

## 异常处理（标注不修正）

- 项目无数据：标注"数据未提供/待补全"
- 同比值缺失：自行计算 (本期−同期)/|同期|，若同期为0则标注"无法计算"
- 多期累计表口径不同：以最新累计期间为准，标注"存在多期累计表，采用最新累计口径"

# 写字楼经营分析（office-operation-report）

写字楼/办公业态经营分析报告的总控技能：读取 BI 取数 Excel，按固定口径与异常规则完成指标计算，
汇总为十一章节的管理层报告，并可输出金鹰暖色财务风 HTML/PDF。

> 开发者：冯杰 · 内部使用 · 报告含敏感经营数据，请只在公司内部流转。

## 安装（金鹰 Agent 插件市场）

在桌面端「插件 → 发现」中搜索「写字楼经营分析」安装即可，安装后注册技能 `office-operation-report`。

## 市场版包含什么

- `SKILL.md`：报告总控流程、口径优先级、sheet 前缀对照、十一章节骨架、自检清单
- `references/knowledge_base/`：指标字典、口径规则、异常规则、报告模板、财务风样式规范、
  BI 取数 Excel 的 sheet 结构与项目名映射（已去除内网地址、账号、Token、卡片 ID 和真实金额）

**不包含**（原交付包里的内部资产）：

- 六个子技能（出租率与空置、合同动态与净吸纳、租金与量价、财务权责与全年预测、竞品对标、
  租户储备与招商漏斗）——市场版可直接按本技能 + 知识库逐章完成，也可以在环境里另装这些子技能后按顺序调用
- BI 取数脚本、OA/BI 认证脚本、PDF 生成脚本、示例报告 HTML 与前端资源

## 前置条件

- 一份 BI 取数产出的 Excel（`data/写字楼经营分析-BI取数_YYYY-MM-DD.xlsx`），或直接上传 Excel 给 Agent
- 报告中涉及的 BI/OA 账号、Token、内网地址一律不随包分发，由使用方自行配置

## 能做什么

- 按 `B权责`、`A基础信息`、`B收入支出明细`、`C合同情况`、`C流失统计`、`D办公业态竞品`、
  `F储备转化分析`、`F储备明细` 等 sheet 前缀定位数据
- 按指标字典和口径规则计算出租率、净吸纳、租金量价、财务权责、全年缺口、招商漏斗
- 按异常规则标注出租率 >100%、空置为负、数据缺失等 10 类异常，严禁编造
- 输出结论先行的十一章节报告（管理层摘要、关键指标、出租率与空置、合同动态、租金量价、
  竞品定位、租户储备、财务权责、风险预警、行动建议、数据口径与异常说明）
- 按财务风样式规范生成 HTML，并按 A4/5mm 边距/封面独占页的规范导出 PDF

## 使用示例

```text
用这份 BI 取数 Excel 出一份 2026 年 10 月的写字楼经营分析报告
先校验一下这份数据里有哪些异常，再生成管理层摘要和风险预警
把这份月报改成金鹰暖色财务风的 HTML，并导出 A4 PDF
```

## 口径要点

- 报告期间 = 当年 1 月 1 日至报告截止日；C 类合同表为「本年累计」口径
- 单位：面积㎡、金额万元、租金元/㎡/天、百分比保留 1 位小数；涨红跌绿
- 数据缺失/异常如实标注「数据未提供/待补全」，不得用推算或虚构数字填充
